# TODOROKI 本番差し替えセット

対象：既存の 2szzrkyhkt-commits/TODOROKI リポジトリと todoroki-gold.com。

このセットは、既存サイトの見た目・記事・無料PDFの導線を更新する差分です。ドメインやDNS、D1、Stripe、Resendの設定変更は含みません。有料PDFは販売準備中のままです。

## 反映

ZIPを展開し、中のファイルとフォルダーを既存リポジトリのルートへ配置してください。assets・vendor・libraryは中身ごと必要です。現在のworker.js・wrangler.jsonc・premium.html・login.html・contact.htmlはこのセットに含まず、既存のものをそのまま利用します。

既存リポジトリの全削除や置き換えはしないでください。PDFフォルダーの原本と決済・ログインのファイルは残します。初回は作業ブランチへコミットし、変更を確認してからmainへ反映できます。

## 変更点

- 従来の記事7本のURLを維持し、新しいデザインで本文を直接配信
- テーマ一覧と無料PDF48件の一覧を静的HTMLでも読めるように変更
- PDF48件に個別の紹介・閲覧ページを追加
- キーワード検索、テーマ/種類の絞り込み、あとで読む、スマホ表示
- canonical・OGP・構造化データ・sitemap・robotsの整備
- 既存のGA4・AdSense・Search Console確認タグは本番ファイルで継承

## 本番反映後の確認

ホーム→既存記事→関連記事→PDF紹介ページ→PDFページ送り→ダウンロードを確認します。既存のpremium.html・login.html・contact.htmlが開くことも確認します。テスト購入やメール送信は行わず、購入ボタンは準備中のままにします。

Search Consoleには同じドメインのsitemap.xmlを使用します。

## 戻す場合

同梱の変更一覧には追加ファイルと更新ファイルが記録されています。バックアップZIPは更新前ファイルの原本です。GitHubで反映コミットを取り消すと、追加ファイルも含めてまとめて戻せます。

本セットは未公開です。公開サイトへの反映・公開範囲の変更はまだ行っていません。
