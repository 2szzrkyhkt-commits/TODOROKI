# 企業評価の公開見合わせ（2026-10-29）
日本企業10社比較の日本語2版・5翻訳を本文抽出して点検。76～85点の独自評価があるが、公開ソース上で点数の配点表・全入力値・原資料との対応を再現できなかった。出典不足自体から違法とは結論しない。法律面の懸念を減らすための編集判断として現行公開を停止し、一般的な企業比較の確認手順に誘導した。

旧PDFの現行ファイルを削除、6言語カタログから除外、PDFサイトマップから除外。旧URLをno-storeの案内へ転送し、出典台帳には公開見合わせと旧版ハッシュを記録。過去のコミット・利用者保存済みの複製まで消去していない。

制度確認：金融庁の投資助言・代理業監督指針（https://www.fsa.go.jp/common/law/guide/kinyushohin/07.html）。無料表示・免責文だけで登録不要と断定しない。一連の行為と収益・契約・個別対応などを総合して判断する必要がある。今回の非公開措置は、当サイトが登録対象に該当したと判定したものではない。
