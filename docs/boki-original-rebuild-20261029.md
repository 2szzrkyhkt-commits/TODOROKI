# 簿記教材の差し替え（2026-10-29）
旧版の文章・設問は市販教材との全件照合ができないため、公開用HTMLから全て取り除いた。旧版の掲載が侵害であったと確定したという意味ではない。

新規作成：商業簿記10、会計学10、工業簿記10、原価計算10の解説と対応する演習計40問。市販誌面・図表・設問の入力や転載は使用せず、一般的な会計上の論点と今回設計した仮定条件により構成。各設問の解説と数値を再計算する。網羅性・試験機関の監修は表示しない。権利侵害が絶対にないという保証や法律意見書ではない。

根拠の区別：ASBJの基準は会計処理の参照先。例題の金額は架空。管理会計の例は設問に示した差額計算・割引計算の仮定によるもので、会計基準が各意思決定の結論を推奨する意味ではない。

旧PDF3件も現行公開ツリーから外し、案内ページへ誘導。過去コミットや利用者が保存した複製まで消去したとは扱わない。権利者の申し出・削除対応は引き続き運営が実施する。
