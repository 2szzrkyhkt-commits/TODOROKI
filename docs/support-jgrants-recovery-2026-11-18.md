# T29 支援制度カタログ収集の停止修復

2026-11-18 JST。JAPAN SUPPORTは非公開を維持し、T29は未完了。

## 現況と原因

別作業で11/17に配備されたJグランツ収集がGitHub mainに未収録だった。
実配備のworker.js/jgrants.jsを読取り、残る9モジュールはmainと末尾空白以外で一致を確認した。
元のLibrary ZIP全体で本番を上書きせず、現行配備を基準に差分だけ修正する。

専用D1の既存8検索語は各22回失敗し、checked_atなし/cursor0/item_count0。
catalog25件は11/17の初回補助保存のまま。予約処理は起動していたが、
Cloudflare Workersのfetchがredirect:errorを受け付けず、外部取得前に失敗していた。

## 修正と不変の範囲

jgrants.jsのredirectをmanualへ変更。3xxも従来の非2xx処理で失敗・再試行となり、
Locationへ追従しない。既存の8キーワード、日次取得、25件ずつ保存、失敗後1時間待機、
カーソル、出典/加工表示、pending状態、既存RPC/公開ロックを維持する。
DBの初期化・手動カーソル変更・新規Cron・取得元追加・添付資料取得はしない。

mainへ未収録だった既存worker.js/jgrants.jsと既存2テーブルのスキーマを収録する。
スキーマファイルは復旧用の記録であり、本番へ再適用・初期値投入はしない。
国の全給付/助成/減免制度の網羅や、受給条件/金額の個別検証・一般公開は未達。
8キーワード検索で全国全制度を取得したとは扱わない。

## 検証

追加3回帰ケースと既存3ケースを実行。旧redirect:errorでは2ケース失敗、修正後6ケース成功。
Workers互換の取得オプション、302非追従、403/不正JSON時の正常スナップショット保持、
再試行予約、25件上限/カーソル、programsの非変更を検証する。
既存RPCの両処理呼出と公開403を維持するテストへ、実配備済みの戻り値形式を反映した。
監視59・条件92・照合1079・金額598・自治体カタログ93検証も成功。
本番の既存周期でchecked_at更新と、その後の25件保存/カーソル進行を確認して正本へ記録する。
