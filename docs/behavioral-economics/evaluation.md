# 行動経済学教材の効果検証

## 目的と既知の状況
- **Behavior**: 読者が、何を学べるか理解してから教材を選び、確認問題と解説を使い、必要なら次章や復習候補へ進める。
- **Analysis**: 変更前の第2部は関連ページへのリンクのみ。公開済みの第3部の確認問題には選択式の回答・復習履歴がなかった。どの操作で実際に利用者が離脱していたかは未確認。
- **Strategy**: 章番号を揃え、復習候補と次章の案内を操作する場面に表示。学習の保存は任意。同調を促す架空の利用者数や通知、ランキングは使わない。
- **Intervention**: 全20章、任意の端末内保存、三択クイズ、前後移動。分析の読み方では実測・推計・不足データの区別と、購入時価格や周囲の評判だけに頼らない確認項目を表示。
- **Change**: 下記の公開指標で確認し、少数の計測だけでは改善を断定しない。自動化や新しい定期実行は追加しない。

## 集計ルール
同意済みのアクセス解析だけを使用。イベントには固定名と章番号のみを追加。回答、正誤、復習リスト、端末内保存内容は送らない。広告・同意・タグの設定は既存のまま。計測には、既存のプライバシー制御で有効になった GA4 のみを使う。

| 指標 | 算出方法と注意点 |
|---|---|
| 教材閲覧 | ページパス `/behavioral-economics` の閲覧数を端末別に比較。章への直接移動を個別ページ閲覧とは扱わない |
| 回答・完了 | `be_study_quiz_submit` は回答操作、`be_study_complete` は任意の学習済みチェック。到達した読者の完全な把握はできないため、同意済みセッション当たりの操作割合として参考表示する。複数回答・チェックし直しを件数だけで完了人数とみなさない |
| 次章・PDF | `be_study_next`、`be_study_pdf` の操作。PDFリンクを押したことと、教材を読み終えたことは区別する |
| 記事・ツール | `be_study_article`、`be_study_tool` のリンク操作。ツール内での利用そのものとは区別する |
| 操作上のエラー | CIの内部リンク・ブラウザエラー・保存失敗時の挙動を確認。利用者ごとのエラー詳細や自由入力は送信しない |

変更前の同意済み閲覧は 2026-11-14〜20 に2回（PCとスマートフォン各1回）。これは初期の参考値であり、効果推定には少なすぎる。既存 Part 3 の問題開示イベント（`be_part3_quiz_open`）と新しい回答行動を混同しない。公開後に同じ長さの期間で集計し、十分な分母、季節要因、流入元の差を確認してから判断する。
