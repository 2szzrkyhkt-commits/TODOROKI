## 取引台帳
- 分割・併合は価格基準切替時点を含め活動を一度だけ適用。決議日・基準日・権利落日・効力日を別項目にする。分割で外部投資元本は変わらない。端数処分が不明なら止める。自己株式取得・消却、新株発行、転換等は会社株数を変えても一般株主の保有数や元本を変えない。希薄化率を実測値に二重に掛けない。
- 株主割当・ライツは行使しない、全行使、一部行使、権利売却を区別し、参加は明示のみ。日付・払込・上限と価格・費用・受取額を証拠に紐づける。合併・株式交換・スピンオフ・TOB・上場廃止は新旧識別子、比率、継承する原価、現金・端数・各銘柄の最終価格を明示し、不足ならゼロではなく未確定。
- 権利落時の適格株数×その時点の1株配当で権利額を計算。支払済み現金と未受領を区別。再投資は受取後の実測株価、税・手数料、取引単位で行い外部投入にしない。配当調整済み価格と現金配当の二重計上を防ぐ。
- 元本、累計外部投入額、保有銘柄別評価額、残現金、外部受取、実現／未実現損益、手数料、税を区別。総損益＝株式等と現金の評価額＋外部受取－外部投入。時点別の為替で円換算し、ドル建てと分離。未実現税は仮想売却のみ。税制・取引費用は設定に基づく試算。期間損益率、XIRR、TWRを区別する。価格は原数値の桁を保持し、金額は最終表示で丸める（実決済等の端数規則を除く）。
- 過去の原数値と比較用株式基準を別保存。EPSの期中加重株数、BPSの期末株数、株価の基準日を混ぜない。増資を分割として過去EPSを変えない。訂正・企業行動をごとに文書日付、版、固有ID、検証状況、適用市場・通貨を保存する。
