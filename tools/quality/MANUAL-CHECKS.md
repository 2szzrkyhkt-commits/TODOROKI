# 配備前のブロッカー

Cloudflare管理画面へのログインがないため、PRプレビュービルドの失敗理由、定期実行Worker/KV、D1バックアップ設定を確認できていない。APIトークンをチャットやソースへ記載しない。既存の本番サイト設定を変更せず、専用監視Workerを使用する。

GitHub issueへの通知到達は検証済みでも、利用者のメール/端末通知の到着は別途利用者が確認する必要がある。
